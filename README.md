## Про проєкт

Цей репозиторій містить вихідний код клієнтського веб-додатка, розробленого в рамках практичної роботи №2 з дисципліни "Основи веб-програмування". Головна мета — реалізація моніторингу показників енергетичного об'єкта в режимі реального часу за допомогою JavaScript.

**Варіант 2:** Вітрова електростанція.

### Основний функціонал:

* **Моніторинг параметрів:** Логічна генерація та відображення швидкості вітру, обертів ротора, виробленої потужності та кута нахилу лопатей.


* **Індикація станів:** Кольорова візуалізація статусів (норма, попередження, критично) та анімація напрямку вітру.


* **Система безпеки:** Автоматичне вмикання гальмівної системи та візуальна сигналізація при досягненні критичної швидкості вітру.


* **Керування оновленнями:** Кнопки для ручного оновлення показників та таймер для автоматичного оновлення.


* **Інтерактивний графік:** Відображення зміни виробленої потужності в часі.


* **Тестова панель:** Кнопки примусового збільшення/зменшення швидкості вітру (±5 м/с) для швидкого тестування критичних станів.

## Технології

У проєкті використані такі технології:

* **HTML5** — семантична структура сторінки.


* **CSS3** — стилізація карток, плавні hover-ефекти та анімації пульсації .


* **JavaScript (ES6)** — логіка генерації даних, робота з DOM, таймерами (setInterval) та обробка подій .


* **Bootstrap 5** — адаптивна сітка та готові UI-компоненти (картки, кнопки, бейджі).


* **Bootstrap Icons** — векторні іконки для інтерфейсу.
  
* **Chart.js** — бібліотека для відмальовування графіка потужності.
